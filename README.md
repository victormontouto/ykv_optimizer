## 📌 Sobre o projeto

O **YKV PRO OPTIMIZER** é uma ferramenta simples e eficiente que automatiza tarefas de manutenção do computador. Com poucos cliques, você limpa arquivos desnecessários, libera memória RAM e deixa o sistema mais responsivo.

## ✨ Funcionalidades

- 🧹 Limpeza de arquivos temporários e cache
- 🗑️ Esvaziamento da lixeira
- 🚀 Liberação de memória RAM
- 📊 Monitoramento de uso de CPU, RAM e disco
- ⚙️ Gerenciamento de programas na inicialização
- 🖥️ Interface simples e fácil de usar

## 📥 Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/ykv-pro-optimizer.git
   ```

2. Entre na pasta do projeto:
   ```bash
   cd ykv-pro-optimizer
   ```

3. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```

4. Execute o programa:
   ```bash
   python main.py
   ```

## ▶️ Como usar

1. Abra o programa (de preferência como **Administrador**)
2. Escolha as opções de otimização desejadas
3. Clique em **Otimizar**
4. Aguarde a conclusão e pronto!
